# Kahyun Kim — personal website

Published at <https://khyitty.github.io> using GitHub Pages from the `main` branch, repository root.

## Updating the website

- Edit `index.html` on GitHub and commit the change to `main`. The site updates after GitHub Pages deploys.
- To replace the CV, upload a new PDF using the exact filename `Kahyun-Kim-CV.pdf` in the repository root, or edit the CV link in `index.html` if you choose another filename. The current public PDF omits the phone number. Check new PDFs for personal details before uploading: older public commits remain accessible in repository history.
- `header.webp` is the generated banner artwork. `portrait.webp` is a compressed copy of Kahyun's supplied portrait.

GitHub Pages is configured at **Settings → Pages → Deploy from a branch → `main` / `(root)`**. No paid domain is required.
